# Organizesee

Software financeiro e segurança de software, de São Paulo.

## Secure SDLC Review

Revisão defensiva de segurança do ciclo de desenvolvimento de software. O trabalho é feito por um engenheiro e termina em um relatório escrito e em correções entregues como pull requests.

**O que revisamos**

- Código de aplicações e APIs: autenticação, autorização, validação de entrada, segredos e dependências.
- Pipeline de CI/CD: permissões, gates de aprovação e cadeia de suprimentos.
- Fluxos com agentes de IA: contratos entre agentes, permissões de ferramentas e tratamento de conteúdo não confiável.
- Controles de avaliação (evals) usados como gate de release.

**Como trabalhamos**

- Escopo, datas e autorização por escrito antes de qualquer acesso.
- Trabalho exclusivamente defensivo, sem testes em sistemas de produção.
- Toda entrega é escrita ou revisada por uma pessoa.
- Encerramento com revogação de acessos e exclusão das cópias de trabalho.

## Implantação de SDLC

Implantamos um ciclo de desenvolvimento de software completo, do pedido à produção.

- **Entrada do trabalho:** estrutura de prompts para construir a partir de uma interação livre ou de um fluxo de atendimento de requisitos.
- **Entrega:** fluxo completo, integrado a revisão de código e testes automatizados.
- **Segregação:** pontos-chave separados antes e durante cada alteração, com validação depois dela.
- **Automação:** de ponta a ponta, ambiente por ambiente.

## Divulgação responsável

Contribuímos com projetos open source. Vulnerabilidades encontradas são comunicadas em privado aos mantenedores, com divulgação coordenada em até 90 dias.
